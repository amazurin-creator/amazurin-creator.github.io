REASON

It thinks before it types.

Codex breaks problems down. You see the plan it formed before any code lands in your file. You can edit the plan. The code follows from it.

CITE

Every suggestion comes with sources.

When Codex writes a function, it shows you the three places in your codebase it learned the pattern from. No more hallucinated APIs.

REFACTOR

Multi-file edits, atomically.

Rename a type, change a contract — Codex proposes the whole edit set, you review one diff, accept all or none. No half-finished states.

LEARN

It gets better in your repo.

Codex builds a per-repo model of your conventions, your linters, your patterns. The 100th suggestion is sharper than the first.
