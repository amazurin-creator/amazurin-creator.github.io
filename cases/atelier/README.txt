Atelier — превью дизайна
─────────────────────────

Как открыть:
  Двойной клик по index.html — откроется в браузере.
  (Или Cmd+O в Chrome/Safari → выбрать файл.)

Что внутри:

  index.html       — лендинг: hero, проблема, 8 шагов пайплайна,
                     графики (cycle time, объём, распределение времени),
                     цитата, три tier-персоны, манифест, футер

  onboarding.html  — подбор тарифа: 4 шага → персональная рекомендация
                     со скидкой −30%, отзывами и таблицей сравнения

  app.html         — демо ЛК (dark mode): сайдбар с 8 шагами,
                     KPI-стрип со sparklines, kanban-пайплайн на 8 lane-ов,
                     Workshop A–L таблица, mini-чарт + activity feed

  pitch.html       — питч-дек на 12 слайдов для прожарки (≈ 6 минут):
                     Hook → Role → Workflow → Method → 8 шагов → Inside
                     → Numbers → Tier → Pricing → Status → Ask.
                     Навигация: ← → · Space · цифры 1–9, 0 · F = fullscreen.
                     Cmd+P → Save as PDF — каждый слайд на отдельной странице.


Кликается всё:
  • RU / EN — переключатель справа сверху, выбор сохраняется
  • Между страницами — навигация в топ-баре
  • В онбординге — выбор опций, slider, после 4-го шага показывается
    paywall с тарифом, скидкой и отзывами
  • Код WELCOME30 в скидочном баннере — копируется в буфер


Адаптация под устройства:
  • Десктоп — полная сетка
  • iPad landscape — компактнее, сайдбар уже
  • iPad portrait / телефон — лендинг-навигация сворачивается,
    сайдбар ЛК превращается в горизонтальный таб-стрип сверху,
    KPI и карточки стэкаются, kanban скроллится свайпом
  • На iOS можно открыть, добавить на Home Screen (Share → Add to
    Home Screen) — будет вести себя как нативное приложение


Замечания:
  • Это статичные HTML-файлы, ничего не нужно ставить
  • Шрифты подгружаются с Google Fonts → нужен интернет
  • Лучше открывать в Chrome / Safari / Firefox последних версий
