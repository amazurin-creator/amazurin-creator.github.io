01 — Контекст 01 — Context

У тебя нет дефицита AI-инструментов.
У тебя нет мастерской. You don't lack AI tools.
You lack a workshop.

i.
Полдюжины вкладок. Half a dozen tabs.

ChatGPT, Apify, Notion, таблицы, DM-донорам — каждый делает один шаг, никто не делает всё. Ты переключаешь контекст двадцать раз в день. ChatGPT, Apify, Notion, spreadsheets, DMs to donors — each does one step, none do the whole thing. Context switches twenty times a day.

ii.
Контекст утекает на стыках. Context leaks at every seam.

Транскрипт — в одном чате. Перевод — в другом. Бриф редактору — в третьем. На каждом стыке теряется час и одна важная деталь. Transcript in one chat. Translation in another. Brief for the editor in a third. Every handover loses an hour and one important detail.

iii.
Команда ждёт. Ты переключаешь окна. Team waits. You switch windows.

Продюсер становится бутылочным горлом, монтажёр простаивает. ТЗ всё ещё в черновике, потому что один человек собирает его руками. The producer becomes the bottleneck; the editor sits idle. The brief is still a draft because one person is hand-assembling it.

02 — Метод 02 — Method

Восемь шагов,
одно окно. Eight steps,
one window.

Каждый шаг знает, что было до него, и готовит вход для следующего. Контекст не теряется — он накапливается. Each step knows what came before it and prepares the input for the next. Context isn't lost — it accumulates.

05 — Манифест 05 — Manifesto

Что мы намеренно
не делаем. What we deliberately
don't do.

Это рабочая мастерская, не demo-витрина. Несколько простых принципов держат продукт от превращения в «ещё один AI-стартап». A working atelier, not a demo storefront. A few principles keep the product from becoming “yet another AI startup”.

Если кажется что мы упёрты — мы упёрты. Сделать «всё для всех» — путь к посредственному продукту. If we seem stubborn — we are. Building “everything for everyone” is the road to a mediocre product.

  • 01
    Operator-first, AI-second. AI ускоряет каждый шаг, но человек решает что зайдёт. Operator-first, AI-second. AI accelerates each step; the human decides what lands.
  • 02
    Один pipeline, не лоскутный feature-list. Каждая фича — на линии Discovery → Handoff. Side-quest без места = отказ. One pipeline, not a patchwork feature list. Every feature lives on the line Discovery → Handoff. Off-line side-quests = rejected.
  • 03
    Pluggable, не lock-in. Telegram сегодня; Linear / Slack / Discord / Webhook — по росту. Production stack — свободное поле, не диктуем. Pluggable, not lock-in. Telegram today; Linear / Slack / Discord / Webhook as you scale. Your production stack is open — we don't dictate.
  • 04
    Скучный paper UI. Это рабочий инструмент. Не «AI tool с неоновым фиолетовым». Скучный = хороший. Boring paper UI. It's a working tool. Not “AI tool with neon purple”. Boring = good.
  • 05
    Reversible на каждом шаге. Audit log хранит before/after. Никаких «нажал — потерял работу». Reversible at every step. Audit log keeps before/after. No “clicked — lost work”.
